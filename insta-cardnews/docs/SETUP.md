# 처음 한 번만 하는 세팅 가이드

**Instagram 로그인 방식** 기준입니다. 페이스북 페이지를 만들 필요가 없어 훨씬 간단합니다.
전체 **20~30분**이면 끝나고, 한 번 해두면 그 뒤로는 손댈 일이 없습니다.

> 📌 예전 방식(**Facebook 로그인** + 그래프 API 탐색기)으로 이미 진행하셨다면
> 이 문서 맨 아래 [부록 A](#부록-a-facebook-로그인-방식으로-하는-경우)를 보세요. 둘 다 지원합니다.

---

## 0단계. 준비물

| 필요한 것 | 없다면 |
|---|---|
| 인스타그램 계정 | 새로 만드셔도 됩니다 |
| 페이스북 계정 | 개발자 로그인용으로만 필요 (페이지는 안 만들어도 됨) |
| GitHub 계정 | [github.com](https://github.com) 무료 가입 |

---

## 1단계. 인스타그램을 프로페셔널(비즈니스) 계정으로 전환

**개인 계정은 자동 게시가 아예 불가능합니다.** 무료이고, 팔로워도 유지되며, 언제든 되돌릴 수 있습니다.

1. 인스타그램 앱 → 내 프로필 → **☰** → **설정 및 개인정보**
2. **계정 유형 및 도구** → **프로페셔널 계정으로 전환**
3. 카테고리는 **작가(Writer)** 또는 **출판물**
4. 계정 유형은 반드시 **비즈니스** 선택

---

## 2단계. Meta 개발자 앱 만들기

> 이미 `cardnews-bot` 앱을 만드셨다면 이 단계는 건너뛰세요.

1. [developers.facebook.com](https://developers.facebook.com) → **시작하기** → 개발자 등록
2. **내 앱** → **앱 만들기**
3. 사용 사례: **기타(Other)** → 앱 유형: **비즈니스(Business)**
4. 앱 이름 입력 (예: `cardnews-bot`) → 만들기
5. 대시보드의 **제품 추가**에서 **Instagram** 을 찾아 **설정** 클릭

---

## 3단계. 액세스 토큰 생성 ⭐ (여기가 핵심)

좌측 메뉴에서 **Instagram** → **Instagram 로그인이 포함된 API 설정** 을 엽니다.

> ⚠️ 바로 아래 있는 "Facebook 로그인이 포함된 API 설정"이 **아닙니다.** 헷갈리기 쉬우니 확인해 주세요.

### 3-0. 먼저 내 인스타 계정을 「Instagram 테스터」로 등록 ⭐ 필수

**이 단계를 건너뛰면 `계정 추가` 를 눌렀을 때
`개발자 역할 권한 부족` 오류가 납니다.** 화면 안내문에도 적혀 있는 선행 조건입니다.

**① 앱에서 초대 보내기**

1. 좌측 메뉴 **앱 역할** → **역할**
2. 아래로 내려가 **Instagram 테스터** 영역에서 **사람 추가**(또는 **Instagram 테스터 추가**)
3. 내 **인스타그램 사용자명**을 입력 → **추가 / 초대 보내기**
4. 목록에 `대기 중(Pending)` 상태로 표시됩니다

**② 인스타그램 앱에서 초대 수락하기**

초대는 **보내는 것만으로는 효력이 없고, 반드시 수락해야 합니다.**

- 인스타그램 앱 → 내 프로필 → **☰** → **설정 및 개인정보**
- **앱 및 웹사이트** (안 보이면 상단 검색창에 `앱`이라고 입력)
- **테스터 초대** 탭 → 내 앱 이름 옆 **수락**

수락 후 개발자 콘솔의 역할 목록을 새로고침하면 상태가 `대기 중` → **`활성`** 으로 바뀝니다.
이게 확인된 뒤에 아래 3-1로 넘어가세요.

### 3-1. 계정 연결

**「1. 액세스 토큰 생성」** 항목의 파란 **`계정 추가`** 버튼을 누릅니다.

1. 팝업이 뜨면 **인스타그램 계정으로 로그인**
2. 권한 요청 화면에서 **모두 허용**
   (콘텐츠 게시 / 댓글 관리 권한이 포함되어야 합니다)
3. 팝업이 닫히면 목록에 내 계정이 추가되고, 옆에 **액세스 토큰이 생성**됩니다

### 3-2. 토큰 복사

생성된 토큰 옆의 **복사 아이콘**을 눌러 어딘가에 잠시 붙여넣어 두세요.
`IGAA...` 로 시작하는 아주 긴 문자열입니다.

> 이 토큰의 유효기간은 **60일**입니다. 갱신 방법은 맨 아래에 있습니다.

### 3-3. 「2. Webhooks 구성」은 건너뛰세요

Webhook은 댓글·DM 알림을 실시간으로 받을 때 쓰는 기능입니다.
**우리 봇은 게시만 하므로 필요 없습니다.** 콜백 URL과 인증 토큰은 비워두세요.

### 3-4. 앱 모드는 「개발」 그대로 두셔도 됩니다

화면 상단의 `앱 모드: 개발 ⬤ 라이브` 토글은 **개발 상태로 둬도** 본인 계정에는 정상적으로 게시됩니다.
라이브로 전환하면 앱 검수(App Review)가 필요해질 수 있으니 그냥 두세요.

❓**만약 게시할 때 권한 오류가 난다면**: 좌측 **앱 역할** → **역할** 에서
내 인스타 계정이 **Instagram 테스터**로 추가되어 있는지 확인하고,
인스타 앱 → 설정 → **앱 및 웹사이트** → **테스터 초대**를 수락하세요.

## 4단계. GitHub 저장소 만들고 코드 올리기

1. [github.com/new](https://github.com/new) 에서 새 저장소 생성
2. 이름은 아무거나 (예: `cardnews-bot`)
3. **공개 범위는 반드시 `Public`(공개)** ⭐

> **왜 공개여야 하나요?**
> 인스타그램 서버가 카드 이미지를 직접 다운로드해 갑니다.
> 비공개 저장소는 인스타그램이 접근할 수 없어 게시가 실패합니다.
> 이 저장소에는 홍보 문구와 이미지만 들어가고, **토큰은 절대 들어가지 않습니다.**

4. `insta-cardnews` 폴더의 내용을 업로드합니다
   (GitHub 웹에서 **Add file → Upload files** 로 폴더째 끌어다 놓으면 됩니다)

---

## 5단계. GitHub Secrets에 토큰 넣기

저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

| Name | 값 |
|---|---|
| `IG_ACCESS_TOKEN` | 3-2단계에서 복사한 토큰 |

**등록할 건 이것 하나뿐입니다.** 계정 ID는 토큰에서 자동으로 찾아옵니다.

> Secrets에 넣은 값은 GitHub에서도 다시 볼 수 없고 실행 로그에서도 자동으로 가려집니다.

---

## 6단계. 시험 발행

1. 저장소 상단 **Actions** 탭 → 좌측 **주간 카드뉴스 자동 게시**
2. 우측 **Run workflow**
3. 먼저 **dry_run 을 체크한 채로** 실행 → 로그에서 캡션과 이미지 URL 확인
4. 문제없으면 dry_run 을 풀고 다시 실행 → **인스타그램에 실제로 올라갑니다**

여기까지 성공하면 이후 **매주 화요일 밤 9시에 자동으로 게시**됩니다.

## 7단계. 프로필 링크 걸기 (매출에 가장 중요) ⭐

인스타그램은 **캡션과 댓글의 링크가 클릭되지 않습니다.** 프로필 링크만 클릭됩니다.
실제 구매 유입은 대부분 여기서 나옵니다.

인스타 프로필 → **프로필 편집** → **링크 추가** →

여러 서점에 있다면 [litt.ly](https://litt.ly) 나 [linktr.ee](https://linktr.ee) 같은

## ⚠️ 60일마다 해야 하는 유일한 관리

토큰 유효기간이 **60일**이라, 만료되면 게시가 조용히 멈춥니다.

### 방법 A — 명령어로 연장 (가장 간단, 1분)

내 PC에서:

```bash
export IG_ACCESS_TOKEN="현재_토큰"
python src/main.py refresh
```

출력된 새 토큰을 GitHub → Settings → Secrets → `IG_ACCESS_TOKEN` → **Update** 에 붙여넣으면 끝입니다.

> 조건: 발급 후 **24시간 이상 지났고 아직 만료되지 않은** 토큰이어야 연장됩니다.
> 즉 만료 전에만 하면 되고, 한 번 연장할 때마다 60일이 새로 시작됩니다.

### 방법 B — 대시보드에서 재발급

3단계를 다시 수행해 새 토큰을 만들고 Secret을 갱신합니다.

> 달력에 **2개월 반복 일정**으로 "인스타 봇 토큰 갱신"을 등록해 두시길 권합니다.
> 게시가 실패하면 GitHub에서 이메일 알림이 오니, 그때 하셔도 됩니다.

## 문제 해결

### 🔴 `계정 추가` 클릭 시 "개발자 역할 권한 부족"

가장 흔한 오류입니다. 아래를 **위에서부터 순서대로** 확인하세요.

| 확인 순서 | 내용 |
|---|---|
| **1. 테스터 초대를 수락했는가** | 가장 흔한 원인. 3-0단계 ②를 안 했거나, 초대만 보내고 인스타 앱에서 수락하지 않은 경우입니다. 역할 목록이 `대기 중`이면 아직 안 된 것입니다 |
| **2. 프로페셔널 계정인가** | 개인 계정이면 연결 자체가 거부됩니다. 1단계를 확인하세요 |
| **3. 브라우저에 다른 인스타 계정이 로그인돼 있지 않은가** | 팝업이 현재 브라우저 세션의 계정을 그대로 집어갑니다. **시크릿 창**을 열어 개발자 콘솔에 로그인하고, 연결할 인스타 계정으로만 로그인한 뒤 다시 시도하세요 |
| **4. 개발자 콘솔의 페이스북 계정이 앱 관리자인가** | 앱을 만든 계정과 지금 로그인한 계정이 다르면 발생합니다. **앱 역할 → 역할**에서 내 계정이 **관리자**인지 확인 |
| **5. 개발자 등록이 끝났는가** | 전화번호·이메일 인증이 미완료면 역할 부여가 막힙니다 |

초대를 수락한 뒤에도 계속 같은 오류가 난다면, **브라우저 캐시를 지우거나 시크릿 창에서** 재시도해 보세요.
Meta 쪽 권한 동기화에 몇 분 걸리는 경우도 있습니다.

> **그래도 안 되면**: [부록 A](#부록-a-facebook-로그인-방식으로-하는-경우)의 **Facebook 로그인 방식**으로 우회할 수 있습니다.
> 인증 경로가 완전히 달라서 테스터 역할 문제를 겪지 않습니다.
> 페이스북 페이지를 하나 만들어야 하지만, 프로그램은 두 방식을 모두 지원하므로
> `IG_AUTH_MODE` 변수만 `facebook` 으로 두면 그대로 동작합니다.

### 그 밖의 오류

| 증상 | 원인과 해결 |
|---|---|
| `code=190` | 토큰 만료·무효. 3단계 재수행 후 Secret 갱신 |
| `code=200` 권한 오류 | 3-1의 권한 허용에서 빠진 항목이 있음. 계정을 제거 후 다시 **계정 추가** |
| 게시는 되는데 댓글만 안 달림 | 댓글 관리 권한 누락. 계정 재연결 |
| 컨테이너 처리 실패 | 저장소가 `Private`인 경우가 대부분. `Public`으로 변경 |
| `(#100)` / 잘못된 ID | `IG_USER_ID` Secret을 잘못 넣은 경우. **Instagram 로그인 방식에서는 이 Secret을 아예 지우세요** (자동 조회됩니다) |
| 아무 일도 안 일어남 | 60일간 저장소 활동이 없으면 GitHub가 워크플로를 자동 중지합니다. Actions 탭에서 **Enable workflow** 클릭 |
| 개인 계정이라 API가 막힘 | 1단계 프로페셔널 전환이 안 된 상태 |

## 부록 A. Facebook 로그인 방식으로 하는 경우

페이스북 페이지를 이미 운영 중이고 해시태그 검색 같은 기능도 쓰실 거라면 이 방식을 택할 수 있습니다.
설정이 더 복잡한 대신 기능이 조금 더 많습니다.

1. 페이스북 페이지를 만들고 인스타 계정과 연결
2. 앱 좌측 메뉴 → **Instagram** → **Facebook 로그인이 포함된 API 설정**
3. **도구** → **그래프 API 탐색기** → 앱 선택 → **사용자 토큰 가져오기**
4. 권한 5개 체크:
   `instagram_basic`, `instagram_content_publish`, `instagram_manage_comments`,
   `pages_show_list`, `pages_read_engagement`
5. **Generate Access Token** → 생성된 단기 토큰을
   [액세스 토큰 디버거](https://developers.facebook.com/tools/debug/accesstoken/)에서 **연장**
6. 계정 ID 찾기: 탐색기에서 `me/accounts` → 페이지 id 확인 →
   `{페이지id}?fields=instagram_business_account` → 안에 있는 `id` 가 `IG_USER_ID`
7. GitHub Secrets에 `IG_ACCESS_TOKEN` 과 `IG_USER_ID` **둘 다** 등록
8. 저장소 → Settings → Secrets and variables → Actions → **Variables** 탭 →
   **New repository variable** 로 아래를 추가

   | Name | Value |
   |---|---|
   | `IG_AUTH_MODE` | `facebook` |

이 방식은 토큰 자동 연장(`refresh` 명령)이 지원되지 않으니, 60일마다 5~6단계를 반복해야 합니다.
